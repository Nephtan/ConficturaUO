## Maintenance rule

When a new answer arrives, preserve its date and scope, link the question it answers, and record whether it is an observation, explanation, proposed change, live fix, or checked source behavior. If it contradicts an existing FAQ answer, update the answer and this register together. A missing confirmation should stay visible rather than being converted into an invented resolution.
