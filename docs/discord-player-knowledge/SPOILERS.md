# Optional destination and quest clues

**This page contains spoilers.** The [starter guide](START_HERE.md) and most of the [FAQ](PLAYER_FAQ.md) can be used without reading it. These are leads actually found in the supplied histories, not a newly verified atlas. World placements, player homes, and custom dungeons can change. Qualified recollections remain qualified below.

## Leads that should not become guaranteed routes

The Virtue chest is not a guaranteed daily pickup at a favorite dungeon. The sage's next quest need not use the same location as the previous one. Old public rune libraries can be moved or guarded. Custom-area ghost exits and extra quest spawns have conflicting history. Use the [corrections register](CORRECTIONS_AND_OPEN_QUESTIONS.md) before planning a long grind around any of these assumptions.
